# 工作台演示版组件规范

适用：正式工作台的新版模式与独立演示站。本规范与 `src/styles/visual-components.css` 一起维护。

## 参考与取舍

- Linear：https://linear.app/now/behind-the-latest-design-refresh — 固定导航与操作位置，让内容优先；避免每加一个交互就叠一层容器和强调色。
- shadcn：https://ui.shadcn.com/examples/dashboard — 统一控件尺寸、边界、间距和状态；沿用现有实现，不引入新的框架依赖。
- Craft：https://www.craft.do/plan — 每日记录与备忘录采用连续文档排版，保留日期与上下文。

## 基础尺度

| 类别 | 约定 |
| --- | --- |
| 间距 | 4 / 8 / 12 / 16 / 24px，工作区大留白 32px |
| 正文 | 14px，行高 1.8；说明与元信息 12px |
| 标题 | 页标题 24px；内容区标题 16px；正文 H2 20px、H3 17px |
| 字重 | 正文 400、控件 500、标题 600 |
| 控件 | 标准高度 34px，工具栏按钮 28px；抽屉触控操作保留较大命中区域 |
| 圆角 | 控件 6px、卡片使用试用参数；不通过选中改变尺寸 |
| 颜色 | 中性背景与灰色边界；蓝色用于行动与选中；完成绿、等待橙、暂停灰、P0 红 |
| 深色 | 复用语义变量，禁止单独写死白底或深蓝输入背景 |

## 状态规则

- 普通、悬停、键盘焦点、选中、禁用与拖放是不同状态，不复用同一个蓝框。
- 输入框聚焦仅改变自身边界；富文本靠光标及工具栏状态表达编辑位置。父卡片不再追加轮廓。
- 按钮保留键盘焦点轮廓。拖动、缩放操作不应改变正文内边距或行高。
- 任务排序保留插入线；跨区域放入采用浅色背景与提示，取消整卡高饱和蓝框。
- 禁用不改变尺寸；选择与置顶分别表达。备忘录列表不显示正文摘要。

## 页面布局

- 项目页两种视图共用页头及可用高度，只有内容区域滚动；总览滚动位置独立记忆。
- 备忘录列表、正文独立滚动，工具栏和保存状态留在可用区域。
- 全屏工作记录达到 980px 可用宽度时并列；每日记录及整理各自滚动。栏标题占独立行，不覆盖正文。
- 中间滑块支持鼠标、方向键及双击复位；移动布局不重建每日编辑器。
- 窄屏减少列数，不压缩到逐字换行；表格保留区域内横向滚动。

## 富文本与兼容

- 每日记录与周五整理三块使用现有 Quill，左右各自一套工具栏操作本栏编辑器；支持标题、加粗、下划线、高亮、列表、缩进、分隔线与段落移动。
- 原有纯文本在显示时转为安全段落，不将旧内容当 HTML 解释；编辑后并存纯文本摘要及独立富文本字段。
- 刷新、切周、抽屉还原、JSON 序列化均保留格式；复制可选富文本、Markdown、纯文本。
- Word 与 OB 的样式受目标软件影响，保证内容、基本列表和格式语义，不承诺像素一致。

## 验收

检查 1920×1080、1366×768、1024×600、390×844 和短窗口，覆盖深浅色、长标题、长正文及列表。
自动测试覆盖保存、旧记录兼容、工具栏作用对象、复制、段落移动、项目切换、独立滚动和拖放。截图反馈尚无法逐张读取的问题仍需用户在实际环境对照确认，不以测试数量代替验收。

## 组件展示与本轮落地

- 演示页顶部“组件展示”打开独立内容视图，保持实际页面DOM、筛选和滚动，不写入业务数据。展示页直接调用taskRow、memoListItem、propertyButton、toolbar、uiDragHandle、bindUiSplitter。
- 共用列表状态由ui-list-item及组件样式定义，普通、悬停、当前项、多选、键盘焦点和拖放不能互相替代。
- 本周/项目推进区采用身份、编辑列、属性三段结构（任务行另有操作区），编辑列尺寸按卡片保存，不再跨页面联动；窄面板显示可展开的渐隐预览。
- 手柄使用同源SVG，图形10×14px、操作区域28×28px，悬停或键盘聚焦出现，布局始终保留位置。
- 分栏底层复用bindUiSplitter，包含指针捕获、取消、方向键和双击复位；工作记录及编辑列接入，其他分栏仍待渐进迁移。
- 搜索分组标题与排序操作共用uiSectionHeading，控件30px紧凑尺寸；下拉选项共用uiChoiceOptions及uiOptionKeydown。
- Esc下方物理键Backquote在演示页全局生效，不排除输入框、富文本、弹窗、大小写或组合输入标志；不插入按键字符，长按只切换一次。关闭先刷新保存；打开/收回保留所在周与布局。系统/输入法若不向网页发送按键事件，网页无法替代系统处理。
- Alt+1/2/3分别为H2/H3/正文，仅在可编辑富文本内处理；中文组字期间不处理格式命令。

## 当前完成边界

23类组件是完整目标清单，本轮先抽取高频列表/手柄/标题/分栏及工具栏作用域；尚未把所有弹窗、日期、附件、全站尺寸控制都迁移为唯一基础实现。组件展示页目前覆盖按钮/状态、任务编辑行、备忘录行、排序、富文本、分栏和空状态。真实输入法、真实账号云同步及附件服务不属于本轮自动验证范围。

## 本轮补充：侧栏、字体、尾部操作与分割线

- 项目与备忘录调用同一个 `uiSidebarItem`，插槽为选择/拖动、标题与可选元信息、辅助信息、最右侧置顶。共用最低高度 76px、标题 16px、两行截断、选中边框、悬停和置顶底色。多选复用拖动位置，不额外挤占标题列。两行标题加元信息可自然增高。
- 普通任务和本周任务的置顶脱离属性换行区，使用固定尾部位置。所有事项表格使用最右侧固定操作列，保留原置顶范围及排序逻辑。没有置顶功能的任务视图不因此新增置顶。
- “调整样式”增加系统优先、等线、苹方、微软雅黑；偏好只写入界面设置，不写入任务、备忘录或 Quill 文档。系统/苹方正文 400、控件 500、标题 600；等线/微软雅黑正文及控件 400、标题使用 700，以适配真实字型。缺失字体明确提示系统回退，不打包分发系统字体。
- 工作记录正文 15px、行高 1.8，其余正文 14px；共享标题层级沿用基础尺度。只切换字体变量，不重建编辑器。
- 分栏和可调尺寸的边界统一为默认可见的 1px 分割线；悬停、键盘聚焦、拖动时仅强调线条，移除旧粗短条及胶囊手柄。操作区域保留原有 8–14px，线条不占新增布局空间。分栏左右调整、高度上下调整；本周计划/复盘、项目列表、今日区和富文本高度支持方向键、范围限制及双击复位。
- 滚动保留原始容器及原生行为；通过原生 CSS 和事件统一滑块外观，操作时显示、约一秒后隐藏，设置可切换“始终显示”。不通过改动 `overflow` 隐藏内容，不增加滚动容器包装。浏览器决定原生细滚动条的最终像素尺寸。
- 每日记录收起入口距右侧边缘 14px，为滚动条留出独立区域；抽屉边界和内容滚动区分开。
- 组件展示复用真实项目/备忘录渲染函数，展示置顶和窄卡片。展示页交互不修改同步数据。

### 本轮验证与边界

- 构建一致性、150 项静态契约及既有业务/同步/工作记录单元检查通过。
- 使用实际浏览器检查项目/备忘录标题、置顶状态、多选前后坐标，340px 示例卡片没有横向溢出。
- 实测本周分栏鼠标拖动由 50% 调至约 58%，双击恢复；本周/复盘键盘调整及复位、工作记录双栏调整可用。复盘富文本高度入口显示为横向细线。
- 检查字体缺失提示与系统回退、操作时/始终显示滚动条设置、工作记录展开及两侧富文本工具栏。
- 当前检查环境没有等线、苹方、微软雅黑，验证了缺失分支；三套实际字型在 Windows/macOS 下的字面粗细仍需设备复核，不能用回退字体截图代替。
- 演示站隔离数据；正式构建保留原有云同步、业务存储键和部署配置。

## 主分支整合与布局修复

- 默认启用新版及顶部外观/组件入口，左侧使用“工作台 · 项目 · 任务 · 工作记录”。原版切换保留。
- 今天页分栏只由拖动分割线绘制边界，删除右侧栏重复边框。
- 工作记录操作栏去除单侧内边距，三个按钮在栏内水平居中。
- 任务条使用明确网格区域，窄卡片的置顶列跨越标题及属性两行；统一首行边框占位，置顶前后高度和命中区域保持一致。
- 新增正式构建的浏览器布局回归，覆盖默认入口、四种窗口尺寸、置顶前后尺寸、分割线拖动、抽屉及放大后的按钮居中。既有业务套件显式覆盖保留的原版样式；每日记录测试按新的双富文本工具栏更新。
# 周选择、日期排序与分割线补充规范

- 本周页与工作记录共用 `openWeekPicker`：月历按周一至周日排列，点击一天或周号选中整周；支持年月切换、本周、方向键和 Esc。日期以本地日期键保存，周标题与选择器统一采用 ISO 周所属年份。
- 项目详情仅显示一个“日期排序”按钮，循环降序、升序、默认；使用完成日期，保留置顶优先和未完成事项的相对顺序，不修改业务数据或手动排序。右下角提示本次排序状态。
- 每个拖动分割线只允许一个 `::before` 绘制 1px 线，禁用旧 `::after`、边框和背景手柄。绘制必须限制在独立命中区内；功能区之间统一 12px 命中区与两侧各 12px 间距。内部编辑器边界同样预留命中区，不允许伪元素越出任务条。
- 今天页等待与催办、临时收件箱之间的横向分割线支持上下拖动、上下方向键和双击复位；高度比例仅在本设备保存，两侧内容保持可滚动。
- 聚焦文本框仅提示文本框本身；任务拖动插入线只在实际拖动期间出现，结束、取消或窗口失焦后清除。
- 周成员记录保留曾安排的任务，移出本周、归档或删除后仍保留已有周计划与结果；历史周读取保存的当周推进内容，禁止用当前下一步替代。历史编辑功能禁用，放大阅读可用。
