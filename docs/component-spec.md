# 工作台演示版组件规范

适用：正式工作台新版模式与独立演示站。本规范与 `src/styles/visual-components.css` 一起维护。

## 参考与取舍

- Linear：https://linear.app/now/behind-the-latest-design-refresh — 固定导航与操作位置，让内容优先；避免每加一个交互就叠一层容器和强调色。
- shadcn：https://ui.shadcn.com/examples/dashboard — 统一控件尺寸、边界、间距和状态；沿用现有实现，不引入新的框架依赖。
- Craft：https://www.craft.do/plan — 每日记录与备忘录采用连续文档排版，保留日期与上下文。

## 基础尺度

| 类别 | 约定 |
| --- | --- |
| 间距 | 4 / 8 / 12 / 16 / 24px，工作区大留白 32px |
| 正文 | 14px，行高 1.8；说明与元信息 12px |
| 标题 | 页标题 24px；内容区标题 16px；正文 H2 20px、H3 17px |
| 字重 | 正文 400、控件 500、标题 600 |
| 控件 | 标准高度 34px，工具栏按钮 28px；抽屉触控操作保留较大命中区域 |
| 圆角 | 控件 6px、卡片使用试用参数；不通过选中改变尺寸 |
| 颜色 | 中性背景与灰色边界；蓝色用于行动与选中；完成绿、等待橙、暂停灰、P0 红 |
| 深色 | 复用语义变量，禁止单独写死白底或深蓝输入背景 |

## 状态规则

- 普通、悬停、键盘焦点、选中、禁用与拖放是不同状态，不复用同一个蓝框。
- 输入框聚焦仅改变自身边界；富文本靠光标及工具栏状态表达编辑位置。父卡片不再追加轮廓。
- 按钮保留键盘焦点轮廓。拖动、缩放操作不应改变正文内边距或行高。
- 任务排序保留插入线；跨区域放入采用浅色背景与提示，取消整卡高饱和蓝框。
- 禁用不改变尺寸；选择与置顶分别表达。备忘录列表不显示正文摘要。

## 页面布局

- 项目页两种视图共用页头及可用高度，只有内容区域滚动；总览滚动位置独立记忆。
- 备忘录列表、正文独立滚动，工具栏和保存状态留在可用区域。
- 全屏工作记录达到 980px 可用宽度时并列；每日记录及整理各自滚动。栏标题占独立行，不覆盖正文。
- 中间滑块支持鼠标、方向键及双击复位；移动布局不重建每日编辑器。
- 窄屏减少列数，不压缩到逐字换行；表格保留区域内横向滚动。

## 富文本与兼容

- 每日记录与周五整理三块使用现有 Quill，左右各自一套工具栏操作本栏编辑器；支持标题、加粗、下划线、高亮、列表、缩进、分隔线与段落移动。
- 原有纯文本在显示时转为安全段落，不将旧内容当 HTML 解释；编辑后并存纯文本摘要及独立富文本字段。
- 刷新、切周、抽屉还原、JSON 序列化均保留格式；复制可选富文本、Markdown、纯文本。
- Word 与 OB 的样式受目标软件影响，保证内容、基本列表和格式语义，不承诺像素一致。

## 验收

检查 1920×1080、1366×768、1024×600、390×844 和短窗口，覆盖深浅色、长标题、长正文及列表。
自动测试覆盖保存、旧记录兼容、工具栏作用对象、复制、段落移动、项目切换、独立滚动和拖放。截图反馈尚无法逐张读取的问题仍需用户在实际环境对照确认，不以测试数量代替验收。

## 组件展示与本轮落地

- 演示页顶部“组件展示”打开独立内容视图，保持实际页面DOM、筛选和滚动，不写入业务数据。展示页直接调用taskRow、memoListItem、propertyButton、toolbar、uiDragHandle、bindUiSplitter。
- 共用列表状态由ui-list-item及组件样式定义，普通、悬停、当前项、多选、键盘焦点和拖放不能互相替代。
- 本周/项目推进区采用身份、编辑列、属性三段结构（任务行另有操作区），编辑列尺寸按卡片保存，不再跨页面联动；窄面板显示可展开的渐隐预览。
- 手柄使用同源SVG，图形10×14px、操作区域28×28px，悬停或键盘聚焦出现，布局始终保留位置。
- 分栏底层复用bindUiSplitter，包含指针捕获、取消、方向键和双击复位；工作记录及编辑列接入，其他分栏仍待渐进迁移。
- 搜索分组标题与排序操作共用uiSectionHeading，控件30px紧凑尺寸；下拉选项共用uiChoiceOptions及uiOptionKeydown。
- Esc下方物理键Backquote在演示页全局生效，不排除输入框、富文本、弹窗、大小写或组合输入标志；不插入按键字符，长按只切换一次。关闭先刷新保存；打开/收回保留所在周与布局。系统/输入法若不向网页发送按键事件，网页无法替代系统处理。
- Alt+1/2/3分别为H2/H3/正文，仅在可编辑富文本内处理；中文组字期间不处理格式命令。

## 当前完成边界

23类组件是完整目标清单，本轮先抽取高频列表/手柄/标题/分栏及工具栏作用域；尚未把所有弹窗、日期、附件、全站尺寸控制都迁移为唯一基础实现。组件展示页目前覆盖按钮/状态、任务编辑行、备忘录行、排序、富文本、分栏和空状态。真实输入法、真实账号云同步及附件服务不属于本轮自动验证范围。

## 本轮补充：侧栏、字体、尾部操作与分割线

- 项目与备忘录调用同一个 `uiSidebarItem`，插槽为选择/拖动、标题与可选元信息、辅助信息、最右侧置顶。共用最低高度 76px、标题 16px、两行截断、选中边框、悬停和置顶底色。多选复用拖动位置，不额外挤占标题列。两行标题加元信息可自然增高。
- 普通任务和本周任务的置顶脱离属性换行区，使用固定尾部位置。所有事项表格使用最右侧固定操作列，保留原置顶范围及排序逻辑。没有置顶功能的任务视图不因此新增置顶。
- “调整样式”增加系统优先、等线、苹方、微软雅黑；偏好只写入界面设置，不写入任务、备忘录或 Quill 文档。系统/苹方正文 400、控件 500、标题 600；等线/微软雅黑正文及控件 400、标题使用 700，以适配真实字型。缺失字体明确提示系统回退，不打包分发系统字体。
- 工作记录正文 15px、行高 1.8，其余正文 14px；共享标题层级沿用基础尺度。只切换字体变量，不重建编辑器。
- 分栏和可调尺寸的边界统一为默认可见的 1px 分割线；悬停、键盘聚焦、拖动时仅强调线条，移除旧粗短条及胶囊手柄。操作区域保留原有 8–14px，线条不占新增布局空间。分栏左右调整、高度上下调整；本周计划/复盘、项目列表、今日区和富文本高度支持方向键、范围限制及双击复位。
- 滚动保留原始容器及原生行为；通过原生 CSS 和事件统一滑块外观，操作时显示、约一秒后隐藏，设置可切换“始终显示”。不通过改动 `overflow` 隐藏内容，不增加滚动容器包装。浏览器决定原生细滚动条的最终像素尺寸。
- 每日记录收起入口距右侧边缘 14px，为滚动条留出独立区域；抽屉边界和内容滚动区分开。
- 组件展示复用真实项目/备忘录渲染函数，展示置顶和窄卡片。展示页交互不修改同步数据。

### 本轮验证与边界

- 构建一致性、150 项静态契约及既有业务/同步/工作记录单元检查通过。
- 使用实际浏览器检查项目/备忘录标题、置顶状态、多选前后坐标，340px 示例卡片没有横向溢出。
- 实测本周分栏鼠标拖动由 50% 调至约 58%，双击恢复；本周/复盘键盘调整及复位、工作记录双栏调整可用。复盘富文本高度入口显示为横向细线。
- 检查字体缺失提示与系统回退、操作时/始终显示滚动条设置、工作记录展开及两侧富文本工具栏。
- 当前检查环境没有等线、苹方、微软雅黑，验证了缺失分支；三套实际字型在 Windows/macOS 下的字面粗细仍需设备复核，不能用回退字体截图代替。
- 演示站继续使用隔离示例数据；正式版整合由 PR #57 维护。

## 布局修复补充

- 今天页移除右侧栏重复边框，保留一个可拖动分割线。
- 工作记录操作栏使用对称布局；70px 操作栏保证按钮组居中且与 10px 缩放操作区分离。
- 任务条使用明确的网格分区，置顶列跨越标题与换行属性，置顶前后边框占位一致。
- 清理点击、滚动及重绘后的旧提示框，防止提示留在原任务位置。
- 工作记录复制失败弹窗保持独立，不将工作记录挂进其自身的复制弹窗。
- 顶部条保留组件展示、版本切换和外观设置，左侧文案为“工作台 · 项目 · 任务 · 工作记录”。界面设置不更改业务存储。
- 页面使用独立格式化上下文容纳顶部留白，避免控件聚焦带动外层上移 42px。

## 执行与复盘共用契约

- 任务行统一为操作区、标题/行动区、属性区、最右置顶区。今天、本周、项目、所有事项使用同一 `taskRow`；批量选择、周推进编辑和项目下一步作为可选插槽。
- 宽度缩小时优先让标题换行、属性换行；规划编辑列按容器断点收纳，保留可点击预览。单条置顶状态不改变列宽和命中范围。
- 项目与备忘录继续使用 `uiSidebarItem`；两者拖动操作区均为 28×28，图标 10×14，垂直居中。语义不同的辅助信息可使用同一插槽。
- 业务状态色仅表达状态；选中、悬停和拖动落点分别表达，不使用整行蓝色焦点框。所有交互保留清晰的单控件键盘焦点。
- 轻量选择窗口使用统一的视口边界定位。状态和优先级选择支持方向键、Home/End、Escape；更多菜单使用同一键盘规则。原生选择增强在支持时进入浏览器弹出层，避免被卡片裁切。
- 富文本继续复用 Quill、工具栏、列表拖动、Alt+1/2/3 和既有保存管线。总结双入口在编辑时同步另一编辑器，不重建正在输入的编辑器。
- 搜索在中文组词期间不重绘，组词结束后更新；保留原输入位置，避免每次输入将光标强制移到末尾。
- 周总结以 `state.weeks` 为唯一编辑来源；旧工作记录字段是兼容镜像，迁移不得吞掉不同的旧正文。记录关联保存任务 ID；整理必须由用户选择段落。

详见 `docs/workflow-demo-iteration.md` 的范围与验收。

## 普通任务条与行内检查清单补充（2026-10-23）

- 普通任务条的几何布局由 `src/styles/task-row-layout.css` 统一管理。置顶、有无置顶功能、历史只读使用明确插槽；状态变化不切换页面专属布局。周推进/项目下一步的规划编辑行是同一文件中的显式独立变体。
- 属性区日期统一使用 `task-row-dates`，不再借用会强制占满一行的通用 `muted` 布局。已完成条优先显示完成日期，计划与截止日期仍保存在事项详情。
- 普通任务条按内容容器宽度响应：560px 及以下属性放在标题/行动区下面；置顶始终独立于属性换行。不同页面可有不同可用宽度，同宽同变体应具有相同几何行为。
- 检查项内容是无边框行内编辑：聚焦只保留插入光标；勾选、拖动、时间、删除按钮继续各自具有操作语义。文字输入、复选框、时间、删除按钮在同一行按中心对齐。
- 本次实测：聚焦后 outline / box-shadow 均为 none；检查项五个插槽中心坐标一致；1920×1080、1024×600、390×844 页面无横向溢出，完成日期与状态/优先级同属属性行；另检查本周规划行及分组行。此范围不能等同全站所有弹窗、表格和编辑器已完全统一。

## 任务详情与工作记录联动（2026-10-23）

- 列表移除独立文字操作行及更多操作菜单，最右仅保留置顶。状态、优先级和日期仍可行内修改；今日/本周安排由详情复选框或检查安排入口维护。下一步正文继续展示和从详情编辑。
- “记工作记录”位于详情左栏项目关系下面。先保存任务草稿，再定位今日记录；只打开不新增任务关联，实际写入后关联一次。
- 普通任务条与规划行的几何均由 task-row-layout.css 管理；新旧界面共用结构与分栏交互，尾部插槽仅保留置顶。
- 详情与记录共享可用宽度规则：1120px 起并排，记录宽度受详情最小可用宽度约束；更小窗口切换任务/记录，保留原编辑器。详情变窄时附件与关联折叠收纳，日期控件占完整字段宽度。
- 工作记录所有模式均从可视区域顶部到底部，不为全局顶栏保留空白；底部显示记录保存状态和账号同步状态。演示数据仅保存到本机。
- 关闭记录恢复详情；关闭详情将记录移回正文层，保持可操作。放大保留每日记录/周五整理双栏，恢复后回到并排。
- 今天页移除顶部四项统计栏，页面标题下直接显示行动与等待区。

- 全高工作记录位于演示顶部条之上，普通页面与弹窗入口遵循同一遮挡关系；关闭后顶部条恢复可操作。标题、周选择和工具栏均需在普通抽屉及放大模式下验证。

- 任务条更多菜单已按用户要求完全删除（含渲染、事件及样式），尾部只保留置顶并恢复 30px；今日/本周安排在详情复选框中维护，状态和日期仍可行内修改。

## 记录到复盘、安排到下周

- 选取记录可带入共享周总结，也可带入某个已有事项的本周实际结果；保留日期、原文及原计划，重复带入去重。关联仍为轻量链接，不新增任务副本。
- 等待事项使用不按日期分类的连续列表，无日期时按钮显示设置跟进日期；不给用户静默填日期。
- 今日/本周的检查安排集中处理继续、改期、移出，确认前不改数据，某行日期无效时不部分保存。移出安排不等于删除或完成。
- 复盘可确认已有事项的下周日期；未来周预览只读任务条，按计划日期进入当前周，到了具体日期再进入今天。等待与暂停事项须先恢复状态，不自动改变。
- 复盘表头统一称本周计划，明确它可调整，不称冻结的原计划。
- 正式构建保留原 main 云端配置、依赖及部署入口，演示构建继续隔离示例数据。

- 检查项文字按稳定 ID 从当前输入区收集，保存及重排前均保留实时输入；新增检查项时取消过期的延迟聚焦，避免快速输入或拖动时抢走光标。
- 本地保存失败时使用全局提示中的重试入口；重试同时刷新工作记录的未保存状态，不能只写入存储却仍阻止页面切换。

- 移出本周同时取消已到期及本周内的计划日期，保留下周及更晚日期；详情复选框、检查安排、移至长期跟进共用此规则，避免下一次保存立即重新加入本周。

## 项目计数与任务条收缩（2026-10-26）

- 项目侧栏只显示未归档且未完成的事项数量；等待与暂停计入，空项目显示 0。数量、标题、置顶继续使用共用侧栏插槽。项目间使用独立的 1px 分割线，不借用拖放落点的伪元素。
- 等待区不按日期分组，置顶和手动顺序保持连续；仅主动点击智能排序才重排。上下分隔线分配可用高度，列表不再叠加固定 460px 上限，末项及其操作完整可访问。收件箱继续使用主滚动。
- 普通任务条在 560px 以上保留右侧属性；以下再把属性移到下方，置顶独占末列。标题使用剩余空间，属性按内容分配宽度。
- 规划行超过 960px 时显示事项、编辑区和属性三列，编辑列宽度偏好受实际卡片宽度约束；561–960px 时编辑区占完整第二行；560px 以下先显示可展开的一行预览。移动编辑区时不得保留空列，无置顶按钮时不预留尾列。
- 空编辑区有用途提示，已输入的文字在拖动分隔线、展开收起、页面切换及重载后保留。
